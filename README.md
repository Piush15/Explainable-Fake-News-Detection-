Explainable Fake News Detection Using Linguistic Behavior Analysis

Overview-
This project develops an Explainable AI-based Fake News Detection system that combines Machine Learning, Natural Language Processing (NLP), and Linguistic Behavior Analysis to classify news articles as Fake or Real.

Unlike traditional black-box models, the system provides interpretable predictions using LIME, allowing users to understand the factors influencing each classification.

Problem Statement
Fake news spreads rapidly across digital platforms and existing AI systems often fail to explain their decisions. This project aims to build a transparent and interpretable fake news detection framework.
